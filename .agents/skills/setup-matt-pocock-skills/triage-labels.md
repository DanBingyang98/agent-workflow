# Triage Labels（Triage 标签）

技能以五个规范 triage 角色说话。本文件把这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| mattpocock/skills 中的标签 | 我们 tracker 中的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估这个 issue |
| `needs-info` | `needs-info` | 等待报告者提供更多信息 |
| `ready-for-agent` | `ready-for-agent` | 完全明确，准备好给离席 agent |
| `ready-for-human` | `ready-for-human` | 需要人类实施 |
| `wontfix` | `wontfix` | 不会处理 |

技能提到角色时（例如「apply the AFK-ready triage label」），使用本表对应的标签字符串。

编辑右列以匹配你实际使用的词汇。
