# GLOSSARY.md 格式

`GLOSSARY.md` 是这个教学工作区的规范语言。所有讲解、练习和学习记录都应遵循它的术语。构建它本身就是学习的一部分：把一个概念压缩成紧定义，是用户理解它的证据。

## 结构

```md
# {Topic} Glossary

{一两句：这个词汇表覆盖的主题。}

## Terms

**Hypertrophy**:
由反复训练带来的机械张力和代谢压力驱动的肌肉增长。
_Avoid_: Bulking, getting big

**Progressive overload**:
随时间系统地增加对肌肉的需求——通过负荷、容量或强度。
_Avoid_: Pushing harder, levelling up

**RPE (Rate of Perceived Exertion)**:
一组动作感受难度的 1–10 自评，10 是力竭、8 意味着还剩两次。
_Avoid_: Effort score, intensity rating
```

## 规则

- **只在用户理解它时加术语。** 词汇表是压缩知识的记录，不是用户读了学习的字典。用户刚被介绍一个概念时，等到他们能正确使用它，再把它晋升到这里。
- **要有主见。** 同一概念有多个词时，选最好的一个，把其余列为要避免的别名。语言就是这样压缩的。
- **定义要紧。** 一两句。定义术语 IS 什么，不是它做什么或怎么做。
- **定义内部用词汇表自己的术语。** 一旦术语进了词汇表，到处优先用它——包括其他定义里。这就是让复杂术语以后更容易理解的东西。
- **出现自然聚类时用小标题分组**（例如 `## Anatomy`、`## Programming`）。术语内聚时平铺列表也行。
- **明确标记歧义。** 如果术语在更广领域里被松散使用，记下解决：「In this workspace, 'set' always means a working set — warm-ups are tracked separately.」
- **理解加深时修订。** 用户第一周写的定义第六周可能错了。就地更新；不要留下过期条目。
