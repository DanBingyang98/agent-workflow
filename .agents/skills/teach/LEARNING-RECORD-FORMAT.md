# Learning Record 格式

学习记录住在 `./learning-records/`，用顺序编号：`0001-slug.md`、`0002-slug.md` 等。惰性创建目录——只有写第一条记录时才创建。

它们是教学的 ADR 等价物：捕获非显然的教训、关键洞见和已声明的先验知识，这些会指引未来会话。它们用于计算最近发展区。

## 模板

```md
# {学到或确立的东西的短标题}

{1-3 句：学到了什么（或确立了什么先验知识），以及它对未来会话为什么重要。}
```

格式就这么多。一条学习记录可以是一个段落。价值在于记录_现在已知_这个和_为什么_它改变接下来教什么——不是填满各部分。

## 可选部分

只有真正增加价值时才包含。大多数记录不需要。

- **Status** frontmatter（`active | superseded by LR-NNNN`）——早期理解被证明错误、被替换时有用。
- **Evidence（证据）** —— 用户如何展示理解（答对问题、完成练习、引用先前经验）。主张可能被重访时有用。
- **Implications（影响）** —— 这对未来会话解锁了什么、排除了什么。非显然时值得记录。

## 编号

扫 `./learning-records/` 找最高编号，加一。

## 何时写学习记录

以下任一为真时写一条：

1. **用户对非平凡的东西展示了真正理解** —— 不只是接触过，而是有证据表明他们能正确使用这个概念。这为接下来教什么设定了新地板。
2. **用户披露了先验知识** —— 「我已经知道 X。」记录它，让未来会话不再重教。也记录声称的_深度_。
3. **误解被纠正** —— 用户先前相信错误的东西，现在明白为什么。这些高价值：它们预测相关主题的未来绊脚石。
4. **mission 因学习而转移** —— 用户发现他们关心的与自己想的不同。交叉链接 [[MISSION.md]] 并更新它。

### 什么_不_够格

- 只是被覆盖的材料。覆盖不是学习。等证据。
- 任何已经作为术语定义被 [[GLOSSARY.md]] 简洁捕获的东西。不要重复。
- 逐会话的活动日志。学习记录不是日记——它们是决策级的洞见。

## 取代

当后来的记录与更早的矛盾时（用户的理解加深或纠正），把旧记录标为 `Status: superseded by LR-NNNN`，不要删除。理解如何演化的历史本身就是有用的信号。
