# 阶段边界（Phase boundaries）

**阶段（phase）** 是会话内的一块工作——拷问、实施、QA。定义刻意模糊：当你心想*「好了，这个做完了」*时，阶段就结束了。

**阶段边界**是两个阶段之间的空隙，也是这个决定唯一该出现的地方。阶段中途没有决定可做——继续，或把剩下的工作拆给子代理。中途 compact 会让 agent 丢掉主线。

## 五个选项

| 选项 | 它做什么 |
| --- | --- |
| **Continue（继续）** | 留在会话里。完全没有上下文切换。 |
| **`/clear`** | 清空上下文窗口，从零开始。 |
| **`/handoff`** | 写一个可移植的 markdown 文件，用它到任何地方播种会话。 |
| **Subagent（子代理）** | 把任务送进它自己的上下文窗口，拿回一份报告。 |
| **`/compact`** | 压缩这份上下文，用摘要播种新会话。 |

## 决策树

在边界处自上而下走。第一个**是**赢。

**1. 你能在这个会话里继续吗？** 两件事让答案是「是」：下一阶段需要这个阶段作为**一手来源**，或者你的[智能区](https://www.aihero.dev/ai-coding-dictionary/smart-zone)（约 150k tokens）还够下一阶段放下。拷问 → 实施是标准的「是」：实施要的是逐字推理，不是摘要。Continue 零成本零损失，所以先排除它。

**2. 上下文对接下来无关吗？** 会话里的一切——探索、决定、死胡同——都可丢弃吗？如果是，**`/clear`**。它是棋盘上最便宜的一步：不花时间，把整个窗口还回来。`/clear` 也不是终结——旧会话保持可恢复。

搞错的代价是单向的。清掉*相关*上下文，你就丢了所做事情背后的**为什么**，读多少遍 diff 都拿不回来。

**3. 你需要交接吗？** `/handoff` 很窄。只有这些时候需要：

- 换**新 harness**（Claude → Codex），
- 移去**新目录**或仓库，
- 把工作交给**同事**，
- 或**阶段中途**发现一个旁支任务、要分叉而不脱轨。

这份清单就是全部条款。`/handoff` 买到的是**可移植性**——一个会旅行的文件。没有东西在旅行，你就不需要它。

**4. 这个任务能离席完成吗？** 它是否足够边界清晰、能在你离开键盘、无需操控的情况下跑？那么发给**子代理**，让这个会话保持原样。自动化审查是标准情况：agent 读 diff 并报告，它跑的时候不需要你。

**5. 否则，`/compact`。** 上下文相关、同一 harness、同一目录，而且你需要留在环里——树落在这里，而且经常落在这里。给它一条指令（`/compact we're going to QA this area`），让摘要保住下一阶段需要的东西。

`/compact` 是**默认，不是首选**。它坐在树底，因为上面四个问题都更便宜或更精确。从它开始的人，失败的形态是：一个全新会话对着被摘要压平的某个决定，自信满满地犯错。

## 一手来源与二手来源

除 **Continue** 外的每一步都把**一手来源**变成**二手来源**——真实的会话，被它的摘要取代。取舍永远是同一个形状：

| 来源 | 信息 | 噪音 | 腾挪空间 |
| --- | --- | --- | --- |
| 一手（Continue） | 完整 | 多 | 小 |
| 二手（`/compact`、`/handoff`） | 有损 | 少 | 大 |

这就是为什么问题 1 排第一。只有当留在原地比换掉更贵时，你才付有损的代价。

## 这些是判断

问题不是客观的——每个都带品味，同一边界两天可以走两个方向。价值在于**按顺序**问它们，在工作中途而不是边界处问就没有这个价值。
